# 🏏 IPL Analytics Dashboard | Power BI

## 📌 Project Overview

The IPL Analytics Dashboard is an interactive Business Intelligence solution developed in Power BI to analyze IPL matches, player performance, team statistics, and venue insights. The dashboard enables users to explore batting, bowling, and match performance through interactive visualizations and dynamic filters.

---

## 🎯 Project Objectives

- Analyze IPL performance across multiple seasons.
- Identify Orange Cap and Purple Cap winners.
- Compare team performance and match results.
- Analyze venue-wise statistics and trends.
- Build an interactive dashboard for cricket analytics.
